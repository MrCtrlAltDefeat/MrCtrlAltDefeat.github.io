One application, three layers

SmartExpense connects a Next.js interface to a FastAPI application and PostgreSQL database. It supports recording expenses, categorizing transactions, and comparing monthly spending against a budget.

From records to a useful dashboard

  • JWT-based authentication connects requests to the signed-in user. Expense queries are scoped by user ID.
  • Expense records include an amount, category, note, and date. The API supports category, note, month, and year filters.
  • The dashboard uses Recharts for category breakdowns and bar charts, alongside monthly totals, recent expenses, and budget progress.
  • The supplied project includes Docker configuration and backend API tests.

Turning transactions into a summary

The analytics endpoint first selects the user’s expenses for a month, then calculates the total and groups amounts by category.

Keeping updates tied to the owner

Updating or deleting an expense queries both the expense ID and the current user’s ID. This keeps the operation scoped to a record owned by the authenticated user.
