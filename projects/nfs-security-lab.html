An isolated security exercise

This demonstration uses Kali and an intentionally vulnerable Metasploitable VM on a NAT network. It examines how exposed file shares can become the starting point for unauthorized access and local privilege escalation inside a controlled lab.

What the lab demonstrated

  • Discovery: an Nmap scan identifies exposed services, including NFS.
  • Misconfiguration: overly broad exports expose directories to a second machine.
  • Initial access: writable account files enable SSH access as a non-root user in the vulnerable VM.
  • Privilege escalation: the walkthrough then investigates a known local udev vulnerability.

What I take from the exercise

A network service is only as safe as its export rules, filesystem permissions, and host patching. The exercise connects service discovery with access control and reinforces the value of narrowing shared directories and testing how their permissions behave from another host.
