Early Detection of the Red Palm Weevil

Ongoing senior design · American University of Sharjah · Spring 2026

Context
Senior design · wireless networking and cloud platform
Project status
Design phase; implementation planned
Tools & methods
ESP32 · LoRa · Acoustic sensing · Cloud classification

Detecting hidden activity

A proposed low-cost IoT acoustic system uses trunk-mounted piezoelectric sensors to capture vibrations associated with larval feeding. The design is minimally invasive and aims to support earlier inspection decisions.

Three layers

  • Sensing: 27 mm piezoelectric disc, MCP6002 amplification, ESP32 processing, and RFM95W LoRa transmission.
  • Processing: bandpass filtering, signal-to-noise gating, and MFCC feature extraction before sending compact feature packets.
  • Gateway: Raspberry Pi 4 receives LoRa packets, buffers locally, and forwards data using MQTT over Wi-Fi or 4G.
  • Cloud: PostgreSQL/TimescaleDB storage, planned CNN / CNN-LSTM / Mamba model comparison, dashboard access, and email alerts.

My responsibilities

  • Lead wireless topology and protocol design, LoRa configuration, packet formatting, reliability, and synchronization testing.
  • Lead cloud server setup, ingestion API, database schema, security, access control, and alert delivery.
  • Own network stability, uptime, data-loss and latency measurement, plus network deployment documentation.

Current stage

Senior Design I establishes the architecture, requirements, development plan, and dashboard prototype screens. Physical implementation, model training, integration, and field validation are planned for Senior Design II.

Evaluation will measure recall, false-negative rate, precision, F1, latency, packet loss, and uptime. Bench emulation will be reported separately from live-infestation field validation.
