A campus escape

A student navigates a university controlled by AI impostor professors. The five-room world links the Lobby, Library, Lab, Server Room, and Exit Gate. Collect the ID Card and USB Drive, disable the server, and escape before health runs out.

Software design

The game separates engine, player, room, professor, and event-manager responsibilities. Professor entities patrol independently on threads and observe player-entry events. The Player class synchronizes damage updates.

Commands include movement, looking around, picking up and using items, inventory, health, and quitting. Room access and item use depend on the game state.
